# 边界与中间图

每页记录：稳定页号、原文件路径/哈希、EXIF转正后尺寸、点评、四角及坐标尺度、目标比例、增强参数、补图来源/掩膜和未恢复位置。

| 点评 | 动作 |
|---|---|
| 左边多了一个边 | 区分墙面/边框与PPT留白，仅去确认的无关区域 |
| 上面裁过了 | 回原图恢复标题，不能在旧裁剪图外补背景冒充恢复 |
| 下面多保留 | 检查结论、图注、页码，单独调整下方两个角 |
| 没放正 | 检查横竖直线，重定平面；旋转不等于透视校正 |
| 不裁剪/我自己裁 | 全照片扩展画布校正，原照片四角全保留，画外留白 |

先确认内容包围范围，再选屏幕边界。原照片没有拍到的部分无法靠扩大裁剪找回。

## 配置

`quad` 顺序左上、右上、右下、左下，坐标基于EXIF转正后照片。可用原像素坐标，或预览坐标加 `coordinate_size`。四角必须构成凸四边形。画外角点仅在真实直线证据足以外推平面时使用，不填造画外内容。

```json
{
  "mode": "crop",
  "coordinate_size": [1600, 1200],
  "quad": [[100, 300], [1500, 150], [1530, 1080], [80, 950]],
  "target_size": [2560, 1440],
  "enhance": {"gain_rgb": [1.0, 1.0, 1.0], "unsharp_percent": 0}
}
```

以上只是格式示例，不是通用裁剪框或推荐比例。

`mode: "full-frame"` 将四角所定义的平面校正，再扩展到包含原照片全部角点。此时 `target_size` 指参考矩形，不是最终画布。如果用表格四角作参考，需有比例依据；估计比例必须说明。地平线穿过照片时不可做此转换，脚本拒绝输出。

输出PNG及 `page-01.png.json` 记录，不覆盖原图或已有结果。中间PNG保留；PPT若因实际大小限制使用JPEG，采用高质量与无色度子采样等保真设置，并检查文字边缘。不要把某次工具的大小上限写成永久规则。
