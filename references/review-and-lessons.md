# 复核与经验

此流程来自讲座照片逐页修订。用户认可最终版本，同时仍有无证据恢复的遮挡和背景接缝。可复用的是逐页参数、保真边界、来源追踪和复核方法，不是某个算法必然成功。

| 已发生的失败 | 下次改变 |
|---|---|
| 标题/结论被裁 | 先确认内容外沿，区别正文线与屏幕边，四个方向分别检查 |
| 统一边界错切 | 每张照片独立参数，同机位也不假设相同四角 |
| 旋转后仍歪 | 用平面四点透视，检查横竖线 |
| 旧裁剪图扩边无效 | 每次回最高分辨率原图，不补造边缘 |
| 背景残留头发/色块 | 放大轮廓、保护正文、排除黑边样本、检查色差纹理 |
| 供图共同遮挡 | 双方掩膜约束修复，不覆盖整个目标人影 |
| 全页生成改动文字 | 正文图表照片只从真实素材补回 |
| 缩略图漏小字 | 总览查页序，单页查四边，局部查笔画拼接 |
| 备注与结果不符 | 根据最终渲染更新，不能照抄计划或工具成功状态 |

## 交付检查

1. 输入照片、输出页和来源对应，按用户保留/合并要求核对数量。
2. 点评页号无错位，认可页嵌入图片及几何布局不变。关系ID重编号不意味着视觉修改，应解析关系而非只比较整页XML字节。
3. 中间图与最终渲染一致，没有cover裁剪、拉伸、空页。全照片校正页等比例容纳。
4. 每页核对标题、结论、图注、页码，放大修补处。结构校验不等于内容准确性检查。
5. 来源/参数可追溯，清单如实保留问题。常规输出新PPTX、按需PDF和清单；用户自行裁切页附PNG。仅要求中间图时不擅自组装PPT。

清单列：`页号 | 来源 | 边界调整 | 修补与供图 | 尚存问题`。不必交付所有内部日志。后续点评只提炼实际复现过的失败原因和检查动作，不因一次认可宣称可自动无损还原所有照片。
